# DECOPRAX — site web V5

Domaine cible : https://www.decoprax.fr
Contact : Decoprax@gmail.com

## Démarrage local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Avant mise en ligne
- Le domaine `decoprax.fr` doit être enregistré au nom de l’entreprise et ses DNS configurés vers l’hébergeur.
- Vérifier que www.decoprax.fr et decoprax.fr redirigent correctement (choisir une URL canonique).
- Remplacer les photos d’ambiance par les photos réelles des chantiers DECOPRAX, après validation des droits d’utilisation.
- Le formulaire actuel ouvre un email via `mailto:` ; connecter un service serveur (SMTP/Resend) pour un envoi fiable.
- Compléter les mentions légales, SIREN/SIRET, adresse, responsable de publication et les activités exactes couvertes par l’assurance décennale.
- Tester `npm run build`, les formulaires, les liens et les Core Web Vitals avant publication.
